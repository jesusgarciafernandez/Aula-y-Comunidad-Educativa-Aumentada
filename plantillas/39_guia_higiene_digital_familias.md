# Guía de higiene digital para familias

> Propuesta para conversar y adaptar en casa; no es una norma del centro.

| Tema | Acuerdo posible | Cómo se revisa |
|---|---|---|
| Dispositivos por la noche | Lugar común y horario pactado | |
| Tiempo de pantalla | Tramos y pausas realistas | |
| Contenidos inapropiados | Qué hacer y a quién pedir ayuda | |
| Apuestas/violencia/suplantación | No compartir, guardar lo mínimo y avisar | |
| Uso de IA | Contrastar, declarar uso y proteger datos | |

## Preguntas para hablar

- ¿Qué te haría pedir ayuda sin miedo?
- ¿Qué límite podemos cumplir de verdad?
- ¿Qué canal oficial usaríamos ante un problema?
