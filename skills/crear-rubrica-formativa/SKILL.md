# Crear una rúbrica formativa

## Cuándo se usa
«Necesito una rúbrica», «cómo evalúo esto», «qué criterios pongo», o automáticamente antes de
`revisar-trabajo-con-feedback` cuando no existen criterios.

## Cuándo NO se usa
- Para calcular notas, ponderaciones o medias: el sistema no califica.
- Para evaluar personas: se evalúan producciones.

## Entradas
Tarea o producción, etapa, resultado de aprendizaje. Opcional: criterios que ya use el centro.

## Pasos
1. Parte del **resultado de aprendizaje**, no del contenido.
2. Selecciona entre 3 y 5 criterios. Más criterios no es más rigor: es más ruido.
3. Escribe cada criterio como algo **observable en la producción**.
4. Define 3 o 4 niveles con descriptores concretos, sin adjetivos vacíos («bueno», «adecuado»).
5. Escribe la versión **en lenguaje del alumnado**, para que sepa qué se espera antes de empezar.
6. Añade una lista de cotejo breve para autorrevisión.
7. Declara qué **no** mide esta rúbrica.

## Contrato de salida
Rúbrica analítica (criterios × niveles con descriptores) + lista de cotejo para el alumnado + qué no
mide + decisión docente pendiente. Plantilla: `plantillas/05_rubrica_y_lista_cotejo.md`.

## Límites
Sin puntuaciones, sin pesos, sin conversión a nota. Sin criterios sobre la persona (actitud, esfuerzo
percibido, madurez).
