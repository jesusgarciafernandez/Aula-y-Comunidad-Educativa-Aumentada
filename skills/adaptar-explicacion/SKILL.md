# Adaptar una explicación

Ejecuta `workflows/W03_adaptar_explicacion.md` con `agentes/A03_adaptador_explicaciones.md`.

## Cuándo se usa
«Explícalo para 4.º de primaria», «esto para familias sin formación técnica», «pásalo a lenguaje
claro», «hazme una versión corta para el claustro».

## Cuándo NO se usa
- Si hay que diseñar la sesión entera → `disenar-actividad-aprendizaje`.
- Si hay que escribir una circular → `preparar-comunicacion-familias-comunidad`.

## Entradas
El concepto y el destinatario. Opcionales: conocimiento previo, idioma, extensión, modalidad.

## Pasos
1. Delimita el concepto.
2. Declara el nivel previo asumido (el más bajo razonable si no consta).
3. Explicación base: idea central primero.
4. Ejemplo cercano al contexto real.
5. Analogía **con su límite declarado**.
6. Error frecuente y cómo se deshace.
7. Comprobación de comprensión (2–3 preguntas o tarea breve).
8. Versión alternativa (más corta, más larga, otra modalidad o lectura fácil).
9. Nota docente sobre lo simplificado.

## Contrato de salida
Concepto · nivel asumido · explicación · ejemplo · analogía con límite · error frecuente ·
comprobación · versión alternativa · nota docente. Plantilla: `plantillas/04_guia_explicacion_adaptada.md`.

## Límite
Si una simplificación introduce un error conceptual, se descarta y se dice por qué.
