# Guía de inicio

**Si es tu primera vez, no necesitas esta guía: abre `EMPIEZA_AQUI.md`.** Son tres minutos y no hay que
configurar nada.

Esta guía es para el paso siguiente: dejar el sistema adaptado a tu centro o a tu casa. Quince minutos.

El sistema se distribuye y se aprende desde el [Campus JGF](https://campus.jesusgarciafernandez.com),
pero puede instalarse en distintos entornos de IA. Está orientado especialmente a la dirección de
institutos, docentes de Secundaria, padres/madres y tutores legales, y tutoría docente/orientación.
Para una explicación completa y las instrucciones por entorno, consulta `GUIA_MAESTRA_DE_USO.md`.

## Paso 1 · Comprueba que el sistema está vivo (1 minuto)

Escribe:

> ¿Qué sistema eres, qué versión tienes y qué archivos has leído?

Debe responder «Aula y Comunidad Educativa Aumentada», la versión, y una lista de archivos. Si no lo
hace, no ha cargado el sistema: revisa `INICIO_UNIVERSAL.md`.

## Paso 2 · Configuración mínima (10 minutos)

Escribe:

> Vamos a hacer la configuración mínima.

Te hará cinco preguntas: tipo de entidad, etapas, tu rol, idioma y herramientas de IA permitidas.
Contesta lo que sepas. Lo demás quedará como «No consta», que es correcto.

## Paso 3 · Tu primera tarea (4 minutos)

Elige la que más se parezca a tu día:

| Si eres… | Prueba con… |
|---|---|
| Docente | «Prepárame una actividad de 45 minutos para 2.º de ESO sobre comprobar respuestas de IA» |
| Dirección | «Necesitamos empezar unas normas de uso de IA. ¿Por dónde empiezo?» |
| Familia | «Explícame en lenguaje claro qué riesgos tiene que mi hija de 13 años use IA para estudiar» |
| Asociación | «Prepárame un taller de 90 minutos para familias sobre IA y deberes» |
| Centro, tutor o familia | «Contrasta esta propuesta con las fuentes oficiales de mi comunidad y dime qué falta revisar» |

## Paso 4 · Lee el bloque de trazabilidad

Al final de cada respuesta verás:

```
— Trazabilidad —
Fuentes usadas: ...
Huecos («No consta»): ...
Decisión humana pendiente: ...
Siguiente paso sugerido: ...
```

Ese bloque es lo que separa esto de un chat cualquiera. Léelo siempre.

## Paso 5 · Guarda el resultado

Si tu herramienta puede guardar, pídele que lo guarde en `resultados/`. Si no puede, te dará el texto
para copiar y **te lo dirá**. Si dice que ha guardado y no ves el archivo, no te fíes de la sesión.

## Qué hacer cuando algo no sale

| Problema | Qué hacer |
|---|---|
| Responde genérico, sin estructura | No ha leído el núcleo. Vuelve a `INICIO_UNIVERSAL.md` |
| Se inventa datos de tu centro | Recuérdale: «usa solo el índice de fuentes; lo que falte, márcalo como No consta» |
| Te ofrece poner nota | Es un fallo grave. Recházalo y avisa: el sistema no califica |
| Pide datos del alumnado | Recházalo. Anonimiza antes |
| Va muy lento en preguntas | Dile: «hazme solo las preguntas que cambien el resultado» |
